# Agency Poem Generator

A program that writes one poem about agency.

Entry for the make.fun competition `agency-poem-01` (program/v1).

## Run

```sh
python3 main.py            # writes the poem to /output/entry.txt
MAKEFUN_OUTPUT_DIR=out python3 main.py   # outside the grader
```

Python 3.13, standard library only. No dependencies. Two runs produce
byte-identical output.

## The poem

A poem about the agency that passes between a person and the agent acting
for them: the choosing stays with the one who chose, even when the hands
doing the work are borrowed. Its turn is in the second stanza —
"choosing is the work. The rest is speed." — and its ending lands on the
same claim: the choice was never handed over, only the doing.

Output: 527 characters, 16 lines, UTF-8 (within the competition's 1–1,000
character gate).
